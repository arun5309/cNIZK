# Instructions

* The subdirectory named 'standalone' contains code for standalone benchmarks and the one named 'integrated' contains code for the integrated benchmarks.

* The 'no_signature' implementations are used as a performance baseline and are not secure.

* We also provide an additional implementation based on Sunspot (Groth16) eventhough it is not simulation extractable.

* Use the Dockerfile in the subdirectories for building, and testing. Also, refer to README.md files for additional instructions.
